01 — The system

      
Everything is written from scratch.

      
No Linux. No libc. No frameworks. Just a Multiboot2 kernel, a handful of drivers, and a shell that boots in under a second.

    


    

      

        
▚

        
VGA text & mode 13h

        
An 80×25 scrolling console with 16 colours, plus register-level switching to 320×200×256 for the desktop — no BIOS calls after boot.

        console.c · vga_hw.c
      

      

        
⌨

        
Interrupt-driven input

        
IRQ1 decodes set-1 scancodes with shift, caps and arrows. IRQ12 decodes three-byte PS/2 mouse packets for the GUI cursor.

        keyboard.c · mouse.c
      

      

        
◷

        
PIT at 100 Hz

        
System uptime, scheduler accounting, game loops and blocking sleeps all run from one programmable interval timer tick.

        pit.c
      

      

        
▤

        
RAMFS + ATA

        
A hierarchical in-memory filesystem with files, directories, append and delete, alongside a PIO ATA/IDE driver for real disks.

        ramfs.c · ata.c
      

      

        
⬡

        
Package store

        
An embedded Multiboot2 archive with FNV-1a verified module images. Install Snake, Pong and the desktop at runtime.

        store.c · gen_store.py
      

      

        
⇄

        
Real networking

        
PCI enumeration, RTL8139 DMA rings, ARP, IPv4, ICMP, UDP, DHCP, DNS and a TCP client that can fetch real web pages.

        pci.c · rtl8139.c · net.c
        See the stack →
      

    

  


  
  

    

      
02 — Networking

      
A network stack that fits in the kernel.

      

        QEMU’s user-mode network gives the guest a virtual Ethernet segment.
        Minimal Desktop negotiates its own address with DHCP, resolves names with DNS,
        and talks HTTP/1.0 over a hand-built TCP client.
      

    


    

      

        
packet path

        

          HTTP GETcurl · store · browser
        

        

          TCP clientseq/ack · 3-way handshake
        

        

          DHCP · DNS · UDPports 68/53
        

        

          IPv4 · ICMPchecksums · ping
        

        

          ARP16-entry cache
        

        

          Ethernet IIRTL8139 · PCI
        

        

      


      

        

          
Auto-IP on boot

          DHCP
        

        

          The kernel probes PCI for a Realtek RTL8139, enables bus mastering, sets up
          RX/TX rings and broadcasts a DHCP DISCOVER before the shell prompt appears.
          QEMU hands back 10.0.2.15/24, gateway 10.0.2.2,
          DNS 10.0.2.3.
        


        

          
NICRTL8139I/O BAR, MAC from IDR

          
L3ARP + IPv4cache, ICMP echo

          
L4UDP + TCPDHCP, DNS, HTTP

          
CLI4 commandsifconfig, ping, nslookup, curl

Rendered desktop

        
Bitmap icons, a dithered gradient wallpaper, window drop shadows and a start menu opened with the Super key — all drawn pixel by pixel.

      

      

        
Terminal & Notepad

        
An in-GUI shell with command output, plus a text viewer for files in RAMFS.

      

      

        
Network connector

        
A GUI panel with live IP/DHCP/MAC status, traffic counters and ping / DHCP-renew / info / DNS actions, plus a small HTTP browser.

      

      

        
Return to console

        
Restores text mode by reprogramming the VGA registers, then resumes the shell where it left off.

Small modules, verified at install time.

05 — Build & boot

      
From source to a QEMU window in one command.

      
The pipeline compiles the kernel and modules, builds the ISO, copies it to D:\minimal_desktop.iso, launches QEMU and streams the self-test over COM1.

    


    

      

        
Windows
build_and_run.bat

        
REM installs nothing; uses WSL Ubuntu
wsl -u root -e bash tools/install_toolchain.sh
build_and_run.bat

REM headless CI test
build_and_run.bat test

      

      

        
Linux / WSL
build_and_run.sh

        
# one-time toolchain
sudo apt install build-essential gcc-i686-linux-gnu \
  nasm qemu-system-x86 grub-pc-bin xorriso mtools

./build_and_run.sh
make test

      

    


    

      
1
Compilei686-elf ABI, freestanding C + NASM

      
→

      
2
Packstore.img, GRUB menu, ISO9660

      
→

      
3
BootQEMU window + serial console

      
→

      
4
Verify13 PASS/FAIL checks, exit 0/1

    


    

      
--autotestGRUB cmdline: run the suite, print to COM1, exit QEMU.

      
make testHeadless: -display none -serial stdio + isa-debug-exit.

      
selftestRun the same checks manually from the shell.
